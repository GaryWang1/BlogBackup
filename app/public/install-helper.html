中文安装说明

Install the Wenxuecity Recommendation Helper

This optional extension checks whether a post has already been recommended. You can use all other website features without installing it.

Download Helper ZIP

  1. Download and extract. Download the ZIP above. In Windows, right-click it and choose Extract All…. Keep the extracted folder in a permanent location, such as Documents → Wenxuecity Helper. Do not delete or move this folder after installation.
  2. Open your browser’s Extensions page. In Chrome, copy chrome://extensions into the address bar and press Enter. In Edge, use edge://extensions. Use the same browser in which you will open the reader website.
  3. Enable Developer mode. Turn on the Developer mode switch on the Extensions page.
  4. Load the extension. Click Load unpacked. Select the extracted folder that directly contains manifest.json. Select the folder, not the ZIP or an individual file.
  5. Refresh the reader website. Confirm that 文学城推贴状态助手 is enabled in your extension list. Return to the reader website and refresh it.
  6. Connect and sign in. Select your forum and click 连接文学城版主账号（可选） (Connect moderator account). Sign in through the official Wenxuecity website in the newly opened tab. Keep that tab open.
  7. Check posts. Return to the reader, choose 推贴, and search. When you return to the reader window, existing recommendation results are checked automatically. Posts confirmed as already recommended cannot be selected. Posts with an unknown status remain selectable.

If the helper is not detected

Check that the extension is enabled in the same browser and browser profile. Click its Reload button on the Extensions page, then refresh the reader website. Use a regular Chrome or Edge window rather than an embedded browser.

When connected, only “已连接文学城。” (Connected to Wenxuecity) is displayed. Installation controls are hidden. Refresh the reader to return to disconnected mode; this does not sign you out of Wenxuecity. The connection message alone does not confirm moderator permissions.

Updating the helper

Download the latest ZIP and extract it to the same permanent folder, replacing the old files. Click Reload on the extension’s card, then refresh the reader website. Updates are manual; this package is not installed through an extension store.

Privacy and supported websites

Enter your password only on the official Wenxuecity website. The helper reads recommendation status locally and does not upload your password, login cookies, or moderator page to the reader server or Gemini. Disconnecting the helper does not sign you out of Wenxuecity.

Supported reader addresses: https://dainty-praline-c54396.netlify.app, http://localhost:3017, and http://127.0.0.1:3017. Moderator permissions are checked separately for each forum.
