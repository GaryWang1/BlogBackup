文学城推贴状态助手安装说明

这是可选扩展。不安装也能使用搜索、合集和 AI 推贴；安装并登录版主账号后，可自动禁选已推荐帖子。

下载助手 ZIP · English instructions

  1. 下载 ZIP，右键选择“全部解压”。将解压后的文件夹保存在固定位置，例如“文档 → 文学城推贴助手”。安装后不要删除或移动文件夹。
  2. 在同一个浏览器的地址栏输入：Chrome 使用 chrome://extensions，Edge 使用 edge://extensions。
  3. 开启“开发者模式”，点击“加载已解压的扩展程序”。选择直接包含 manifest.json 的文件夹，不要选择 ZIP 或单个文件。
  4. 确认“文学城推贴状态助手”已开启，返回阅读器并刷新页面。
  5. 选择论坛，点击“连接文学城版主账号（可选）”。在打开的文学城官方页面登录。账号密码只在文学城页面输入，并保持该标签页打开。
  6. 返回阅读器，选择“推贴”和时间范围，点击“下一步”。已推荐帖子会自动禁选；无法确认的帖子会显示原因，仍可选择。回到阅读器窗口时也会自动检查已有推贴结果。

连接状态

连接后仅显示“已连接文学城。”，安装入口会隐藏。此提示表示扩展已连接文学城页面，不代表已验证版主权限；权限以每篇帖子的检查结果为准。刷新阅读器可返回未连接状态，不会退出文学城账号。

更新和排错

更新时下载最新 ZIP，解压覆盖原文件夹，在扩展管理页面点击“重新加载”，然后刷新阅读器。未检测到助手时，检查是否在同一个浏览器和用户配置中安装并启用扩展。请使用普通 Chrome 或 Edge 窗口，不要使用内置浏览器。

扩展不上传密码、Cookie 或完整版主页面，只向阅读器返回推荐状态。支持当前 Netlify 正式网站及本地 3017 端口。
